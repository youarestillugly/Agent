# Start Here

1. Open `DAT404_Data_Quality_Detective.ipynb` for the markdown-led project notebook.
2. Read `README.md` for installation and execution.
3. Install dependencies: `pip install -r requirements.txt`
4. Start Ollama and pull Qwen3: `ollama pull qwen3:8b`
5. Launch the app: `streamlit run app.py`
6. Upload a CSV or Excel workbook in the app.
7. Work through `PROJECT_CHECKLIST.md` and complete the report/evaluation templates.

Important: run the supplied tests and your own evaluation before claiming results.
