# Evaluation Log

Run each test in `test_cases.csv`. Record:
- date/time and machine configuration
- Ollama version and exact Qwen3 model tag
- dataset name and row/column count (do not include private data)
- expected tools and actual tools selected
- success/failure and reason
- latency in seconds
- whether the explanation was grounded in tool evidence
- corrective action taken

Summarise metrics only after all test runs are complete.
